# R2WAI AI Development Knowledge Base

This folder is designed to be copied into the existing R2WAI repository.

## Purpose

Give AI coding agents a structured, persistent source of truth for:
- product direction
- architecture
- existing codebase discovery
- backend
- frontend
- database
- API integrations
- AI agents
- RAG
- providers
- automation
- security
- testing
- deployment
- configuration
- migration
- observability
- task execution
- architectural decisions

`05-CODEBASE-MAP.md`, `reports/CODEBASE-AUDIT.md`, and `reports/FEATURE-GAP-ANALYSIS.md` intentionally contain `TBD / VERIFY` sections because they must be populated from the actual repository rather than invented.
