# Definition of Done

A task is complete only when all applicable gates are satisfied.

## Discovery

- [ ] Existing implementation inspected
- [ ] Reusable code identified
- [ ] Dependencies understood
- [ ] Acceptance criteria clear

## Backend

- [ ] Correct layer used
- [ ] Validation implemented
- [ ] Authorization implemented
- [ ] Error handling implemented
- [ ] Logging appropriate
- [ ] No duplicate service/entity/controller

## Frontend

- [ ] Existing design system reused
- [ ] Loading state handled
- [ ] Empty state handled
- [ ] Error state handled
- [ ] Accessibility considered
- [ ] No fake production data

## Database

- [ ] Existing schema inspected
- [ ] Migration reviewed
- [ ] Indexes reviewed
- [ ] Tenant/workspace isolation verified
- [ ] Data preservation verified

## AI

- [ ] Tool schema validated
- [ ] Parameter validation implemented
- [ ] Policy enforced
- [ ] Approval enforced where needed
- [ ] Execution audited
- [ ] No unrestricted tool access
- [ ] No private chain-of-thought exposed

## Testing

- [ ] Unit tests
- [ ] Integration tests
- [ ] E2E where applicable
- [ ] AI evaluation where applicable
- [ ] Security tests where applicable
- [ ] Build succeeds
- [ ] Tests pass

## Documentation

- [ ] Relevant AI documentation updated
- [ ] ADR created if architectural decision changed
- [ ] Task report completed

## Final report

State:
- what changed
- what was reused
- tests run
- test results
- migrations
- security impact
- known limitations
- TBD items

Never claim completion without evidence.
